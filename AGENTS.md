# Orientações para este projeto

Este é um projeto independente para o Hack Brasil 2026. Desenvolva a implementação aqui, sem copiar código privado anterior do Nexus comercial ou importar seu histórico Git. Ideias de produto podem orientar o trabalho; se houver dúvida sobre materiais anteriores, consulte a organização antes de reutilizá-los. Registre a origem e respeite as licenças de componentes de terceiros.

Mantenha interface e documentação em português do Brasil. Não leia nem imprima arquivos `.env`; use `.env.example` com valores fictícios. Não versione segredos, dados reais, `.next`, `dist`, `coverage`, `node_modules` ou arquivos gerados. A demo deve usar dados fictícios. Cubra cálculos e regras financeiras com testes unitários significativos. Não prometa retorno, segurança financeira ou aconselhamento personalizado.

Consulte `docs/regras-hack.md` antes de alterar o fluxo de entrega ou o repositório. Revise a precisão de qualquer informação antes de divulgá-la como funcionalidade implementada.
